QUESTION 1 - HOW MUCH IS EACH MEMBER BORROWING?

Reasoning:
I need to include every member, including members who have not borrowed any books, so I used a LEFT JOIN between members and checkouts.

SQL Query:

SELECT
    m.member_id,
    m.first_name,
    m.last_name,
    COUNT(c.checkout_id) AS checkout_count
FROM members AS m
LEFT JOIN checkouts AS c
    ON m.member_id = c.member_id
GROUP BY
    m.member_id,
    m.first_name,
    m.last_name
ORDER BY m.member_id;

QUESTION 2 - WHICH BOOKS MATCH A CHOSEN AUTHOR PATTERN?

Reasoning:
I chose the letter A as my author pattern and used LIKE with the A% pattern to find authors whose names start with A.

SQL Query:

SELECT
    book_id,
    title,
    author
FROM books
WHERE author LIKE ?
ORDER BY title;

QUESTION 3 - WHAT ARE THE MOST POPULAR BOOKS?

Reasoning:
I counted how many times each book was checked out, sorted the results from highest to lowest, and selected the top five books.

SQL Query:

SELECT
    b.book_id,
    b.title,
    COUNT(c.checkout_id) AS checkout_count
FROM books AS b
LEFT JOIN checkouts AS c
    ON b.book_id = c.book_id
GROUP BY
    b.book_id,
    b.title
ORDER BY checkout_count DESC
LIMIT 5;

QUESTION 4 - WHO ARE THE MOST ACTIVE READERS?

Reasoning:
I counted the checkouts for each member, sorted the members from highest to lowest, and selected the ten members with the most checkouts.

SQL Query:

SELECT
    m.member_id,
    m.first_name,
    m.last_name,
    COUNT(c.checkout_id) AS checkout_count
FROM members AS m
JOIN checkouts AS c
    ON m.member_id = c.member_id
GROUP BY
    m.member_id,
    m.first_name,
    m.last_name
ORDER BY checkout_count DESC, m.member_id

QUESTION 5 - WHAT DOES A NEIGHBORHOOD'S ACTIVITY LOOK LIKE FURTHER BACK IN TIME?

Reasoning:
I chose Maadi as the neighborhood, sorted its checkouts from newest to oldest, and skipped the ten most recent checkouts to look further back in time.

SQL Query:

SELECT
    m.member_id,
    m.first_name,
    m.last_name,
    m.neighborhood,
    c.book_id,
    c.checkout_date
FROM members AS m
JOIN checkouts AS c
    ON m.member_id = c.member_id
WHERE m.neighborhood = ?
ORDER BY c.checkout_date DESC
LIMIT -1 OFFSET 10;

REFLECTION - WEB PAGE VS DATABASE

The library database is structured for programs to query directly, while the Reading Kickoff data is stored on a web page designed for people to read. Because the Reading Kickoff checkouts were published on an HTML page instead of being stored in the database, we had to extract the table from the webpage and then make its columns match the database checkout data before combining the two sources. This mattered because the final dataset needed to contain both groups of checkouts in one consistent structure.
